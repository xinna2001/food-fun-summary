# 798 艺术区（798 Art District）

## 一句话结论

由 1950 年代东德援建 798 电子厂老厂房改造的包豪斯风格当代艺术园区，UCCA、木木美术馆、长征空间等画廊密集，园区免费入园、展馆多为 10:00–18:00 且周一闭馆，适合情侣拍照、看展、喝咖啡逛潮店，半天到一天行程；个别特展单独售票。

- 评分：携程门票页"798 艺术区"评分 4.5/5（入选北京亲子景点榜，2026-03-09 更新，第三方渠道评分）[S4]；大众点评一手星级本轮未读取。
- 好评要点（公开攻略与媒体归纳）：
  - 工业风出片：包豪斯老厂房、红砖管道、涂鸦墙、火车头广场、751 工业装置，是情侣/单人拍照的高频机位 [S2][S5]
  - 展览密度高：UCCA 尤伦斯当代艺术中心、木木美术馆、长征空间、北京公社、今格空间、东京画廊、爱马思艺术中心等常年有展 [S2][S3]
  - 逛吃一体：园区内咖啡、独立书店、潮玩市集、live 演出可串成一天行程 [S3]
- 差评/注意：
  - 大部分展馆周一闭馆，去之前先在"798 艺术区"小程序确认当日展览
  - 园区很大且指示牌不算密集，容易走冤枉路，建议按"北门进 → UCCA → 798 艺术中心 → 涂鸦墙 → 火车头广场"经典路线走 [S7]
  - 商业气息逐年加重，部分店铺偏网红打卡；对工业建筑和当代艺术没兴趣的人可能觉得"半天就够"
