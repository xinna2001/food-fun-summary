# Farmily米舍（南馆公园店）

## 一句话结论

藏在东城区东直门南馆公园西门内的童话田园风面包坊+Brunch西餐小木屋，环境治愈、拍照出片，人均约 ¥80–100，适合逛公园、遛弯、下午茶和轻食早午餐；属于“拍照好看且味道不踩雷”的公园系网红店，周末和秋季布景期可能需要等位。
